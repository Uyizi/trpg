# Qwen3.5 定制模型与文字冒险：源码学习版

本仓库用于阅读和讲解完整源码，不附带模型权重，也不承诺克隆后即可运行真实模型。技术主文档见[项目技术说明与演示讲解](项目技术说明与演示讲解.md)，包含技术栈、六张流程图、训练和推理过程、应用规则、实际限制及PPT建议。

## 代码阅读范围

| 目录 | 内容 |
|---|---|
| `models/` | 纯文本Qwen加载、双专家LoRA、NF4、量化KV、融合内核、CUDA Graph、生成、检索与终端交互 |
| `scripts/` | 训练、下载工具、导出、启动和性能实验源码 |
| `local-trpg/src/local_trpg/` | FastAPI、模型子进程、角色提示、规则引擎、记忆、事务与存档 |
| `local-trpg/web/` | React/TypeScript前端源码及依赖、构建配置 |
| `local-trpg/modules/` | 两个冒险的结构化规则和场景数据，包含主持人资料与剧透 |
| `src/qwen_debugger/` | 案例重放、输入变换、确认、版本对照与实验工作台 |
| `tests/`、`local-trpg/tests/` | 既有行为样例与边界检查代码，按需阅读 |
| `examples/` | 调试器输入和配置样例 |
| `assets/` | 离线公式显示使用的第三方前端资源和许可证 |

## 源码与生成文件的区别

缓存、量化、专家路由和MTP的**实现代码**属于学习范围，完整保留。它们产生的权重、索引和缓存数据没有收录。

本包排除了虚拟环境、node_modules、编译产物、模型及LoRA权重、训练检查点、原始语料、向量库、SQLite记录、凭据、官方冒险PDF、历史设计稿和中间运行日志。`SOURCE_FILES.txt`列出实际收录文件。

CPU规则引擎、前端和学习用样例与真实GPU推理有不同依赖。依赖声明保留供阅读；现有本地依赖清单引用专用环境，不能理解成跨机器的一键部署说明。要重新运行真实模型，仍需单独准备模型bundle、分词器、兼容依赖和设备。

## 可选与实验路径

MTP、原生NVFP4投影和压缩KV预填充实验的代码保留，便于理解设计和取舍；它们不代表默认全部启用。当前默认配置与限制以主技术文档及源码为准。

## 来源与示例化处理

基础模型来自Qwen；技术原理、框架和冒险来源列在主技术文档。KaTeX等第三方资源保留其许可证，不因此改变第三方授权。本包没有替第三方内容另行授予许可，也没有将其列为原创算法。

发布副本中的个人WSL路径改成`/home/example/...`，个人云端SSH别名改成`YOUR_DSW_SSH_ALIAS`。这些是学习占位值；原工作目录中的对应文件未改动。
